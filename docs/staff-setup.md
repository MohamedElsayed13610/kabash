# Staff app setup (orders board, alerts, printing)

## 1. Database (once)
Run these in the Supabase SQL editor, in order, if you have not already:
`supabase/migrations/0001_schema.sql`, `0002_touch_updated_at_search_path.sql`, `0003_push_subscriptions.sql`, then `supabase/seed.sql` (sample menu).

## 2. Create the first owner account
The password is typed in your terminal (hidden). It is never written to a file or sent anywhere except Supabase.

```bash
node --env-file=.env.local scripts/create-owner.mjs you@example.com "اسمك" owner
```

It asks for the password twice, creates the login and the `owner` profile, and tells you to sign in at `/staff/login`.
More staff: run it again with `manager` or `cashier` (a staff screen comes in the admin phase).
To switch someone off, set `active = false` on their row in the `profiles` table.

Roles: `owner` (everything), `manager` (menu, offers, orders), `cashier` (orders only).

## 3. Push notifications (new-order alerts when the app is closed)
- Keys are generated by `node scripts/generate-vapid.mjs` into `.env.local`: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` (secret), `VAPID_SUBJECT`.
- Put all three in Vercel > Project > Settings > Environment Variables (Production), then redeploy. Set `VAPID_SUBJECT` to a real `mailto:` address or your site URL.
- **Push needs HTTPS.** It does not work on `http://192.168...` on a phone. Test it after deploying to Vercel (or on `localhost` from the same computer).
- On each staff device: open `/staff`, sign in, tap **تفعيل الصوت**, then **تفعيل الإشعارات**, allow notifications, then **جرّب الإشعار**.

| | Android (Chrome) | iPhone / iPad |
|---|---|---|
| Alarm sound while the board is open | Yes (tap تفعيل الصوت once per visit) | Yes (same) |
| Push when the app is closed | Yes, works in the browser | Only after **Add to Home Screen** (Safari > Share > Add to Home Screen) and opening it from that icon. iOS 16.4 or newer. |
| Installable app | Yes ("Install app" / Add to Home screen) | Add to Home Screen |
| Alarm sound when the screen is locked | No: the OS shows the notification sound instead | No: the OS shows the notification sound instead |

The repeating alarm is played by the open page. A locked or closed phone gets the system notification (with vibration) instead. For a cashier tablet, keep the board open: the screen is kept awake once the sound is enabled.

## 4. Printing
Open an order, tap **طباعة**, choose 58 mm or 80 mm paper, and print from the browser (or add `?auto=1` to the slip URL to print on open). Pick the thermal printer in the print dialog and set margins to "None" if it asks.
